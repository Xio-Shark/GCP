# Prompt Launcher (提示词启动器)

**一个极简的 Windows 本地提示词管理工具，基于文件驱动，可粘贴到任意应用程序。**

## 功能特性

- **全局热键唤起**：默认快捷键 `Alt+Space`
- **即时搜索**：快速搜索 `.md` / `.txt` 格式的提示词文件
- **自动粘贴**：支持自动粘贴模式或仅复制模式
- **文件夹监听**：自动热重载提示词文件夹
- **右键打开源文件**：快速编辑原始提示词文件
- **快速打开提示词文件夹**：一键访问提示词目录
- **系统托盘菜单**：显示/隐藏/退出快捷操作
- **开机自启动**：可选的 Windows 开机启动
- **Rust 端模糊匹配**：针对大量提示词集的高性能排序
- **独立设置页面**：包含热键指引
- **轻量级搜索优先启动界面**
- **剪贴板追加**：发送时可选择追加剪贴板内容
- **收藏功能**：
  - 收藏切换快捷键：`Ctrl+Shift+F`
  - 收藏过滤快捷键：`Ctrl+Shift+G`
- **最近使用**：
  - 最近使用过滤快捷键：`Ctrl+Shift+E`
  - 清除最近记录快捷键：`Ctrl+Shift+R`
- **搜索结果高亮**：搜索时在列表中显示匹配片段
- **标签过滤**：通过 `#tag` 输入实现可点击的标签过滤
- **中文界面**：默认中文 UI

## 快速开始

### 前置要求

- Node.js
- Rust 工具链
- Tauri Windows 开发环境

### 安装运行

```bash
npm install
npm run tauri dev
```

### 运行测试

```bash
cd src-tauri
cargo test
```

## 数据模型

- 每个提示词是一个单独的文件
- 标题 = 文件名（不含扩展名）
- 标签可通过文件名中的 `#tag` 或 `[Tag]` 编码
- 文件夹名称自动成为标签
- 搜索匹配文件名、标签、预览内容和完整正文

## 默认配置

- **提示词文件夹**：`Documents/PromptLauncher/Prompts`
- **配置文件**：`AppConfig/config.json`（Tauri 应用配置目录）
- 空提示词文件夹会自动生成示例文件

## 操作说明

- `Enter` = 粘贴（当自动粘贴关闭时为复制）
- 右键点击 = 打开文件
- 双击 = 粘贴

## 适用场景

- **AI 提示词管理**：管理和快速调用各类 AI 提示词
- **代码片段管理**：存储常用代码模板
- **文本模板**：管理邮件、文档等常用模板
- **知识库管理**：本地文件驱动的轻量知识库

## 技术栈

- **前端**：Svelte + Vite
- **后端**：Rust + Tauri
- **UI 语言**：中文（默认）
